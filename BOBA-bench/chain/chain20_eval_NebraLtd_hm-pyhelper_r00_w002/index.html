  • When the collection contains all recognized manufacturing-error names, the same false result is required.
  • Both list and tuple error collections are supported.

  • The supplied url must be stored on the instance and be accessible via the url attribute.

Format of a JSON-RPC Request

Each method call issues a single HTTP POST to the client's url via requests.post(url, json=<payload>).

The base payload has the form of this JSON-RPC 2.0 request object:

{'jsonrpc': '2.0', 'id': 1, 'method': <method_name>}

When a method requires parameters, a 'params' key is added to this base payload (see the individual methods below). No extra keys beyond those described may appear in the payload.

When the HTTP response is successful, its body is a JSON object containing a top-level "result" key. Each method extracts and returns data derived from that "result" value.

Error Handling

Errors are raised at request time, i.e. when a method that performs a request is invoked:

  • Malformed URL: If the configured url is not a valid URL (e.g. 'fakeurl'), issuing a request raises MinerMalformedURL.
  • Connection failure: If the configured url is valid but unreachable (e.g. 'http://notarealminer:9999'), issuing a request raises MinerConnectionError.

Methods

Every method below performs one JSON-RPC request. For each, the payload's method field and the return value are specified.

get_height(self)
  • Payload method name: 'info_height'
  • Returns the entire "result" value (a dict), e.g. {'epoch': 25612, 'height': 993640}.
get_region(self)
  • Payload method name: 'info_region'
  • Returns the entire "result" value (a dict), e.g. {'region': 'EU868'}.
  • Raises MinerRegionUnset if the "result" contains {'region': None} (region unset).
get_summary(self)
  • Payload method name: 'info_summary'
  • Returns the full "result" value, i.e. the summary dict.
get_peer_addr(self)
  • Payload method name: 'peer_addr'
  • Returns the full "result" value (a dict), e.g. {'peer_addr': '/p2p/...'}.
get_peer_book(self)
  • Payload method name: 'peer_book'
  • The payload additionally includes: 'params': {'addr': 'self'}
  • Returns the full "result" value (e.g. a list, which may be empty []).
get_firmware_version(self)
  • Payload method name: 'info_summary' (the same request as the summary)
  • Returns only the string value present at the "firmware_version" key of the summary "result", e.g. '2021.10.18.0'.
create_add_gateway_txn(self, owner_address, payer_address)
  • Positional arguments: owner_address comes first, payer_address second.
  • For this call, the JSON-RPC "result" is a dict that contains a nested "result" key, and that key's value is a base64-encoded transaction string.
  • Returns a dict containing exactly the following keys:
    • 'gateway_address': the public address of the gateway, derived/decoded from the transaction.
    • 'owner_address': the owner_address argument that was passed in.
    • 'payer_address': the payer_address argument that was passed in.
    • 'fee': the transaction fee (an integer).
    • 'staking_fee': the transaction staking fee (an integer).
    • 'txn': the base64-encoded transaction string (i.e. the nested "result" value).

Dependencies

The client relies on the requests library for HTTP. Decoding the add-gateway transaction requires parsing of the Helium blockchain transaction protobuf format and encoding of public keys in Helium's address format.
