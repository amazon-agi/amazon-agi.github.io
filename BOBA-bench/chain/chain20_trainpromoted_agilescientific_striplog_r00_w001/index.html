Task Specification: striplog Package

Implement a Python package named striplog that models geological rock descriptions, intervals, and striplogs. The following classes must be importable directly from the top-level package:

from striplog import Component
from striplog import Lexicon
from striplog import Decor
from striplog import Legend
from striplog import Interval
from striplog import Striplog

1. Component

Represents a rock/material described by a set of named attributes.

Construction

Component(properties) where properties is a dict mapping attribute names (strings) to string values, e.g. {'colour': 'grey', 'grainsize': 'vf-f', 'lithology': 'sand'}.

Attribute access

Each key of the input dict becomes an attribute accessible via dot notation. Attribute names are lowercased when accessed, but the values are stored/returned exactly as passed:

rock = Component({'colour': 'grey', 'grainsize': 'vf-f', 'lithology': 'sand'})
rock.colour      # 'grey'
Equality

Two Component instances are equal when their attributes match case-insensitively on both keys and values. That is:

Component({'colour': 'grey', 'grainsize': 'vf-f', 'lithology': 'sand'})
== Component({'grainsize': 'VF-F', 'colour': 'Grey', 'lithology': 'Sand'})   # True

and unequal when values differ semantically:

Component({...'sand'...}) != Component({...'sandstone', grainsize 'Coarse'...})   # True

!= must behave as the logical negation of ==.

summary(fmt=...)

Returns a formatted string. fmt is a Python format string whose replacement fields name component attributes. Field names are case-insensitive, and:

  • A lowercase field name yields the value as stored.
  • An uppercase field name yields the value uppercased.

Example:

rock = Component({'colour': 'grey', 'grainsize': 'vf-f', 'lithology': 'sand'})
rock.summary(fmt="My rock: {lithology} ({colour}, {GRAINSIZE})")
# 'My rock: sand (grey, VF-F)'

When called with no arguments, summary() must return a non-empty string describing the component (used elsewhere; e.g. a component whose only attribute is lithology='volcanic' summarizes to 'Volcanic').

Component.from_text(text, lexicon)

Classmethod. Parses a free-text rock description using a Lexicon and returns a Component equal to the one that would be built from the parsed attributes. For example, parsing 'Grey coarse sandstone.' with the default lexicon must yield a component equal to Component({'grainsize': 'Coarse', 'colour': 'Grey', 'lithology': 'Sandstone'}).

A Component must be usable as a membership target: component in striplog (see Striplog).

2. Lexicon

Holds vocabularies for parsing geological text (synonyms, abbreviations, and category word lists such as colours, grainsizes, lithologies).

Lexicon.default()

Classmethod returning a ready-to-use lexicon populated with sensible built-in vocabularies sufficient to satisfy the behaviors below.

find_synonym(word)

Returns the canonical term for a word that has a synonym mapping; e.g. find_synonym('Halite') returns 'salt'. Words without a synonym should return the word itself.

expand_abbreviations(s)

Expands whitespace-separated abbreviations in a string to their full words, preserving order and spacing as single spaces. Example:

lexicon.expand_abbreviations("lt gn ss w/ sp gy sh")
# 'lighter green sandstone with spotty gray shale'

The abbreviation set must include at least: lt→lighter, gn→green, ss→sandstone, w/→with, sp→spotty, gy→gray, sh→shale.

The default lexicon must be able to parse strings such as 'Grey coarse sandstone.' into colour/grainsize/lithology attributes.

3. Decor

A display style bound to a Component.

Construction

Decor(d) where d is a dict that includes:

  • 'component': a Component instance
  • 'color' (or 'colour'): a colour, e.g. a hex string '#86F0B6'
  • 'width': a numeric width
Attributes
  • decor.component — the stored Component.
  • decor.colour — the colour normalized to a lowercase hex string (e.g. '#86f0b6'). Both color and colour input keys map to this.
  • decor.rgb — the colour as an (r, g, b) integer tuple, e.g. (134, 240, 182).

4. Legend

An ordered collection of Decor entries mapping colours/widths to components.

Legend.from_csv(csv_text)

Classmethod. Builds a legend from a CSV string. The first line is a header naming columns. Column names may be prefixed with component to indicate a Component attribute. Supported header (whitespace around commas must be tolerated):

colour, width, component lithology, component colour, component grainsize

Each subsequent row provides a colour, a numeric width, and component attribute values (lithology, colour, grainsize). Empty fields are allowed. Each row becomes one Decor.

Example input has 19 data rows (one all-blank component with colour #FFFFFF, width 0).

Legend.default()

Classmethod returning a built-in default legend.

Indexing and iteration
  • legend[i] returns the i-th Decor; legend[1].colour returns the normalized lowercase hex ('#f7e9a6').
  • Iterating a legend yields its Decor objects in order (so [d.colour for d in legend] gives all colours; the example legend has length 19).
get_colour(component)

Returns the lowercase hex colour of the Decor whose component matches the given component. Matching is component equality restricted to the attributes present in the legend entry — a legend Decor matches a queried component when all of the legend component's specified attributes agree (case-insensitively) with the queried component. Examples with the CSV above:

  • A component {'colour':'grey','grainsize':'vf-f','lithology':'sand'} maps to '#eeeeee' (matching the blank/whitespace-only component entry, which normalizes to that default colour when no lithology is specified).
  • A component {'colour':'red','grainsize':'vf-f','lithology':'sandstone'} maps to '#ffdbba'.
get_width(component)

Returns the numeric width (as a float) of the matching Decor. For the red vf-f sandstone above, this is 3.0.

get_component(colour)

Given a hex colour string, returns the Component of the matching Decor. For '#f7e9a6', the returned component has lithology == 'sandstone'.

5. Interval

A depth/elevation interval containing one or more components.

Construction

Interval(a, b, components=[...]) where a and b are numeric boundaries and components is a list of Component objects. The two boundaries may be given in either order (top-first or base-first).

Attributes
  • interval.components — the list of components.
  • interval.primary — the first component in the list.

6. Striplog

An ordered sequence of Interval objects.

Construction

Striplog([iv1, iv2, ...]).

order

A Striplog determines its ordering from its intervals:

  • 'elevation' when intervals are ordered bottom-up (each interval's first boundary greater than its second, decreasing depth going down the list).
  • 'depth' when intervals are ordered top-down (increasing depth).
Length, start, stop
  • len(striplog) — number of intervals.
  • striplog.start — the shallowest boundary value across all intervals.
  • striplog.stop — the deepest boundary value across all intervals.

For a set of elevation-ordered intervals spanning 100–200, order == 'elevation', start == 100, stop == 200. For depth-ordered intervals spanning 80–250, order == 'depth', start == 80, stop == 250.

Indexing

striplog[i] returns the i-th Interval (supports negative indexing). Each interval exposes .primary and .components.

Striplog.from_img(imgfile, start, stop, legend=...)

Classmethod. Builds a striplog from an image file whose colour bands are interpreted against the given legend, spanning depths start to stop. Returns a Striplog.

Striplog.from_csv(csv_string, lexicon=...)

Classmethod. Builds a striplog from a CSV string of the form top, base, description per line (whitespace tolerated), parsing each description into components via the lexicon.

find(term)

Returns a Striplog (subset) of intervals whose components match the search term (e.g. a lithology name like 'sandstone'). The result:

  • Is indexable, and each returned interval exposes .components.
  • Has a .cum attribute giving the cumulative thickness of the matched intervals.
depth(d)

Returns the Interval covering depth d; .primary.lithology gives its primary lithology.

to_las3()

Returns a non-empty string representation of the striplog.

Membership

component in striplog returns True when a Component equal to one contained in any interval is present.

top

Attribute yielding a grouped/summarized view of the striplog; it must support len(...).

striplog.component.Component

Represents a rock component described by a dictionary of properties.

Construction

Component(properties) takes a dict mapping property names, such as 'colour', 'grainsize', and 'lithology', to values.

Attribute access

Each key of the properties dict must be accessible as an attribute. For example, Component({'colour': 'grey', ...}).colour == 'grey'.

Truthiness
  • A Component built from an empty dict {} must be falsy.
  • A Component with at least one meaningful property is truthy.
Equality
  • Two Components are equal if they represent the same properties. Comparison of property values is case-insensitive; for example, equivalent values such as 'grey' and 'Grey' compare equal.
  • Components with differing properties compare unequal.
  • Comparing a Component to a non-Component object, such as a string, returns False rather than raising an exception.
summary(fmt=..., default=...)

Returns a formatted string describing the component.

  • fmt is a Python str.format-style template using property names as fields. Field names are matched case-insensitively against the component's properties, so both {colour} and {GRAINSIZE} resolve appropriately.
    • For {'colour': 'grey', 'grainsize': 'vf-f', 'lithology': 'sand'}, the template "My rock: {lithology} ({colour}, {GRAINSIZE})" returns "My rock: sand (grey, VF-F)". An all-uppercase field name causes its value to render in uppercase.
    • A property whose value is None renders as an empty string. For {'grainsize': 'Coarse', 'colour': 'Grey', 'lithology': None}, the template "My rock: {lithology}" returns "My rock: ".
    • If fmt refers to a field that does not correspond to any property of the component, raise ComponentError.
  • If the component is empty and a default argument is provided, summary(default=d) returns d unchanged.
from_text(text, lexicon, required=None) (classmethod)

Parses free text into a Component using a Lexicon.

  • Component.from_text('Grey coarse sandstone.', lexicon) produces a component equal to Component({'grainsize': 'Coarse', 'colour': 'Grey', 'lithology': 'Sandstone'}).
  • If required names a property that the parsed component does not contain, return a falsy value (None).

find_synonym(word)

striplog.legend.Decor

A Decor associates a component with display properties. It must also be importable directly with from striplog import Decor.

Construction

Decor(params) accepts a dictionary containing:

  • 'component': the stored Component;
  • either 'colour' or the American-spelling alias 'color': a hexadecimal colour string or a supported matplotlib colour name;
  • 'width': a numeric display width.

Both colour-key spellings map to the public .colour attribute. Within a Decor, the display colour is normalized to lowercase six-digit #rrggbb form whether it was supplied as hexadecimal or as a supported name. The numeric width is available as .width and may be represented as a float.

For example:

rock = Component({
    'colour': 'grey',
    'grainsize': 'vf-f',
    'lithology': 'sand',
})
decor = Decor({'color': '#86F0B6', 'component': rock, 'width': 3})

The resulting object satisfies:

  • decor.component is rock and decor.component.colour == 'grey';
  • decor.colour == '#86f0b6';
  • decor.rgb == (134, 240, 182), an integer (red, green, blue) tuple equivalent to .colour;
  • decor.width == 3.0.

striplog.interval.Interval

Represents a single lithologic or stratigraphic interval bounded by a top and a base, holding one or more Components.

Construction

Interval(top, base, description, lexicon=..., components=...)

  • top and base are numeric bounds, exposed as the float attributes .top and .base.
  • If a free-text description and a lexicon are supplied, the description is parsed through the lexicon into the interval's .components, a list of Components. For example, Interval(20, 40, "Grey sandstone.", lexicon=lexicon) yields a component with colour == 'grey' and lithology == 'sandstone'.
  • Alternatively, an explicit list may be supplied with the components keyword, e.g. Interval(120, 100, components=[r1]), and is stored as .components.
Properties
  • .primary is the first component in .components.
  • .thickness is the absolute difference between the bounds, abs(base - top), as a float.
summary(fmt=...)

Returns the string "{thickness:.2f} m of {formatted components}", where the thickness is rendered with two decimal places and each component is rendered using the component-style template fmt (multiple components are joined into a single phrase).

  • For Interval(20, 40, "Grey sandstone.", lexicon=lexicon) and fmt="{colour} {lithology}", the result is "20.00 m of grey sandstone".
  • For Interval(40, 65, "Red sandstone.", lexicon=lexicon) with the same template, the result is "25.00 m of red sandstone".
Comparison

Intervals compare by thickness:

  • Two intervals of different thickness are unequal.
  • > compares thicknesses, with the thicker interval greater. Thus max(interval_a, interval_b) returns the thicker interval.
Addition
  • interval + other_interval returns a new Interval whose .components is the concatenation of both intervals' components and whose bounds span both intervals. For adjacent intervals 20–40 and 40–65, the merged interval has two components and satisfies base - top == 45.0.
  • interval + number extends the interval by that numeric amount and returns a new interval with increased thickness. For a 20-unit-thick interval, interval + 5 has .thickness == 25.0.
  • Adding an unsupported type, such as a string, raises IntervalError.

striplog.striplog.Striplog

An ordered collection of Intervals.

Construction

Striplog(list_of_intervals)

  • Constructing from an empty list raises StriplogError.
  • Intervals are ordered automatically, and the detected ordering is exposed as the .order attribute:
    • If every interval has its base above its top (base < top)—that is, the intervals are defined bottom-up in elevation—then .order == 'elevation'.
    • If every interval has its base below its top (base > top)—that is, the intervals are defined top-down in depth—then .order == 'depth', and the intervals are ordered by increasing top.

For example, given:

iv1 = Interval(120, 100, components=[r1])
iv2 = Interval(150, 120, components=[r2])
iv3 = Interval(180, 160, components=[r1, r2])
iv4 = Interval(200, 180, components=[r3, r2])

a Striplog containing all four has length 4, .order == 'elevation', .start == 100, and .stop == 200.

Conversely, a Striplog built from top-down intervals such as 80–120, 120–150, 180–200, and 200–250 has length 4, .order == 'depth', .start == 80, and .stop == 250.

.start, .stop, and .order
  • .start is the minimum bound across all intervals.
  • .stop is the maximum bound across all intervals.
  • After modifying the striplog's contents, .start and .stop reflect the new extents.
Length, iteration, indexing, replacement, and deletion
  • len(striplog) is the number of intervals.
  • Iteration yields intervals in order; for example, [iv.thickness for iv in striplog] has one value per interval.
  • striplog[i] gets the i-th interval.
  • striplog[i] = interval replaces the i-th interval.
  • del striplog[list_of_indices] deletes multiple intervals at the supplied integer indices in one operation.
Addition

striplog_a + striplog_b returns a new, ordered Striplog containing all intervals from both operands. Two two-interval striplogs therefore produce a four-interval striplog with their combined extents.

find_gaps()

Returns a collection identifying gaps between intervals, and an empty or otherwise falsy result when no gaps exist. Introducing discontinuities by replacement or deletion increases the number of gaps accordingly; deleting N intervals from a contiguous log produces N gaps.

prune(limit=...)

Removes intervals thinner than limit, in the same units as interval thickness, modifying the striplog in place.

anneal()

Closes gaps in place. After annealing, find_gaps() is empty or falsy.

find(term)

Searches for intervals whose primary component, components, or description match term, such as a lithology name. It returns a striplog-like result that:

  • supports indexing, so .find('sandstone')[1] returns an interval;
  • has a .cum property giving the cumulative thickness of matching intervals.
depth(d)

Returns the interval present at depth d; its primary lithology is available as .primary.lithology.

thickest(n=...) and thinnest(n=...)

Return the n thickest or thinnest intervals as an indexable, striplog-like result. For example, thickest(n=7)[1] and thinnest(n=7)[1] return intervals whose .primary.lithology can be inspected.

.cum

The cumulative thickness of all intervals in the striplog.

.top

A summary of the striplog's contents: it contains one entry for each distinct primary component, grouping the intervals' primary components according to component equality. Each entry pairs a component with the cumulative thickness of the intervals whose primary equals that component, and the entries are ordered by decreasing cumulative thickness. Consequently, len(striplog.top) equals the number of distinct primary components in the striplog.

to_las3()

Returns a non-empty LAS3 string representation.

to_log()

Returns a numeric log representation supporting two-dimensional indexing; for example, to_log()[1][5] returns a floating-point value.

Membership

component in striplog returns True when that component occurs in any interval's components.

Striplog.from_csv(text, lexicon=...) (classmethod)

Parses CSV text with one top, base, description interval per line, tolerating surrounding whitespace and using the lexicon to parse each description. The resulting striplog's .top property behaves as defined above; its length equals the number of distinct primary components parsed from the descriptions. For example, a CSV whose descriptions parse to seven distinct components yields len(striplog.top) == 7.

Striplog.from_array(array, lexicon=...) (classmethod)

  • from_image(imgfile, start, stop, legend=..., ...) reads the image over the depth or elevation range from start to stop.
