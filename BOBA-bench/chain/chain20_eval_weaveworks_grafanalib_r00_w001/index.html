Overview

Add support for Grafana's Discrete panel to the public grafanalib.core API. The addition consists of the Discrete panel type identifier, a text-to-color mapping helper, and a Panel-compatible Discrete panel. Existing panel behavior and existing color constants must remain compatible.

Public API Location

The following names must be defined in grafanalib.core and be directly accessible when that module is imported (for example, as G.DISCRETE_TYPE, G.DiscreteColorMappingItem, and G.Discrete):

  • DISCRETE_TYPE
  • DiscreteColorMappingItem
  • Discrete

DISCRETE_TYPE

Add a string constant named DISCRETE_TYPE. It is the Grafana panel-type identifier for the Discrete panel. Discrete.to_json_data() must use this constant unchanged as the value of its serialized type field.

Existing GREY1 Constant

GREY1 remains the existing public color object in grafanalib.core; it must not be redefined as a string or otherwise changed for this feature. It is the default color object for a discrete color mapping.

This default is an intentional exception to the validation applied to caller-supplied colors: in the current API, GREY1 is an RGBA object rather than a string.

DiscreteColorMappingItem

Constructor
DiscreteColorMappingItem(text, color=GREY1)
  • text is required and must be a string. Supplying any non-string value must raise TypeError.
  • color may be supplied positionally or by keyword.
  • When the caller explicitly supplies color, its value must be a string. An explicitly supplied non-string value must raise TypeError.
  • When color is omitted, construction must succeed and the value must default to the existing GREY1 object even though that object is not a string. String-only validation therefore applies only to explicitly supplied color values.

No particular exception message is required.

to_json_data()

to_json_data() returns a mapping containing at least:

  • text: the original text string.
  • color: the explicitly supplied color string, or the GREY1 object itself when color was omitted.

The omitted default must not be eagerly converted to an RGBA string or another representation at this stage. For example:

item = DiscreteColorMappingItem('foo')
data = item.to_json_data()

assert data['text'] == 'foo'
assert data['color'] is GREY1

custom = DiscreteColorMappingItem('foo', color='bar').to_json_data()
assert custom['color'] == 'bar'

Discrete Panel

Discrete must have the same public construction and shared serialization conventions as the existing Panel class. It must accept the inherited panel arguments and defaults, including datasource, targets, title, repeat settings, transformations, and extraJson, in the same positional and keyword order used by other panel classes.

The constructor additionally accepts:

  • colorMapsItems: a list of DiscreteColorMappingItem objects. It is keyword-capable and defaults to an empty list when omitted.

The historical first positional panel argument must remain accepted. It is distinct from an explicitly configured serialized title: calling Discrete('foo', colorMapsItems=...) must not cause 'foo' to appear in the serialized title field. If no explicit title is configured, the inherited title default remains the empty string. An explicit title= value continues to follow normal Panel behavior.

to_json_data()

to_json_data() returns the normal shared panel mapping and includes at least:

  • colorMaps: the colorMapsItems list supplied to the constructor.
  • type: DISCRETE_TYPE.
  • title: the inherited panel title; this is '' when no explicit title was configured.

At this method boundary, colorMaps must preserve the provided list and its DiscreteColorMappingItem elements unmodified. It must not eagerly replace those elements with their serialized dictionaries. The returned field must therefore compare equal to the original list, and implementations that retain the original list object should expose that same object. Nested conversion may occur later through the package's normal JSON encoding process.

Example:

color_maps = [
    DiscreteColorMappingItem('bar', color='baz'),
    DiscreteColorMappingItem('foz', color='faz'),
]

panel = Discrete('foo', colorMapsItems=color_maps)
data = panel.to_json_data()

assert data['colorMaps'] == color_maps
assert data['type'] == DISCRETE_TYPE
assert data['title'] == ''

Compatibility and Scope

  • Keep these additions in grafanalib.core; no separate module is required.
  • Preserve all existing Panel construction, shared fields, serialization, and raw extraJson extension behavior for the new panel.
  • Do not change the type or serialization behavior of the existing GREY1 constant.
  • Do not eagerly serialize the mapping objects inside Discrete.to_json_data().
