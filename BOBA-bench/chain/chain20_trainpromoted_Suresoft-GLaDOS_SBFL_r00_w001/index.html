Outcome-vector polarity

The established SBFL outcome convention must be retained:

  • y[i] == 1, True, or another nonzero value denotes a passing execution.
  • y[i] == 0 or False denotes a failing execution.

This polarity applies to spectrum construction and to every suspiciousness formula, including Kulczynski1. It must not be inverted.

  • n_p[j] is the number of passing executions that do not cover element j.
  • e_f[j] is the number of failing executions that cover element j.
  • n_f[j] is the number of failing executions that do not cover element j.

  • np be the number of passing executions that do not cover the element (n_p).

Public API

The relevant class is SBFL, importable from the library's public surface (the same location from which existing formulas such as Kulczynski1 are already provided). You must extend it so that the following usage works:

sbfl = SBFL(formula='Kulczynski2')
sbfl.fit(X, y)
scores = sbfl.scores_
Constructor
  • SBFL(formula='Kulczynski2') — the formula keyword argument selects the scoring formula by name. The string 'Kulczynski2' must be a recognized value.
fit(X, y)
  • X is a 2D coverage matrix. Each row corresponds to a single test execution; each column corresponds to a program element (component). An entry indicates whether a given element was covered (executed) by a given test.
  • y is a 1D array of test outcomes aligned with the rows of X, indicating for each test whether it failed or passed.
  • fit computes a suspiciousness score for every program element (column) using the selected formula, and stores the results.
scores_
  • After fit has been called, scores_ holds the computed suspiciousness score for each program element, indexed by column position (element 0 is at scores_[0], etc.).

Kulczynski2 Formula

For each program element, four coverage counts are derived from X and y:

  • e_f — number of failing tests that cover the element.
  • e_p — number of passing tests that cover the element.
  • n_f — number of failing tests that do not cover the element.
  • n_p — number of passing tests that do not cover the element.

The Kulczynski2 suspiciousness score for an element is:

score = (1/2) * ( e_f / (e_f + n_f)  +  e_f / (e_f + e_p) )

That is, the average of two ratios: the fraction of failing tests that cover the element, and the fraction of element-covering tests that failed.

  • An element covered by all failing tests and covered by exactly one third of the covering tests being passing (i.e. where the first ratio is 1 and the second ratio is 1/2) yields 3/4; more generally, the score is exactly (1/2) * (e_f/(e_f+n_f) + e_f/(e_f+e_p)) evaluated with the four counts above.

Existing formulas and behavior of the SBFL class must remain unchanged.

Notes on Coverage Counting

  • A test row and an element (column) combination is "covering" when that element's entry for that test is truthy/covered.
  • Failing vs. passing status of each test is determined from the corresponding entry of y.

Overview

Provide spectrum-based fault localization through the SBFL class. The class converts test coverage and outcomes into per-element spectra, computes suspiciousness scores using a selected formula, and ranks program elements from most to least suspicious. Existing score-computation behavior must remain compatible while adding score ranking with the required tie policies.

Public API

The following class and exceptions are available from sbfl.base:

from sbfl.base import SBFL, NoFailingTestError, NotSupportedFormulaError
Construction
SBFL(formula='Ochiai')
  • formula is the case-sensitive name of the suspiciousness formula.
  • The default is 'Ochiai'.
  • The supported names are:
    • 'Ochiai'
    • 'Tarantula'
    • 'Jaccard'
    • 'RussellRao'
    • 'Hamann'
    • 'SorensonDice'
    • 'Dice'
    • 'Kulczynski1'
    • 'Kulczynski2'
  • An unsupported formula name raises NotSupportedFormulaError.
  • A newly constructed instance exposes scores_, initially set to None.

Input Model and Outcome Encoding

Methods that consume coverage data use:

  • X: a dense, 2-D array-like coverage matrix with shape (num_tests, num_elements). Rows represent test executions and columns represent program elements. A truthy/nonzero entry means that the test covered the element; a falsy/zero entry means that it did not.
  • y: a 1-D array-like with length num_tests. A truthy/nonzero value denotes a passing test, while a falsy/zero value denotes a failing test. This polarity applies consistently to spectrum extraction, all formulas, and ranking.

X and y must have compatible sample counts and the required dimensions. Inputs are interpreted as Boolean coverage/outcome data. At least one failing test must be present; otherwise, NoFailingTestError is raised.

Spectrum Extraction

get_spectrum(X, y)

Compute and return a spectrum directly from the supplied data:

e_p, n_p, e_f, n_f = sbfl.get_spectrum(X, y)

This method accepts X and y on every call and must be usable on a freshly constructed instance without a preceding call to fit. It is not a zero-argument accessor over previously fitted state.

For every element/column, the returned one-dimensional arrays contain:

  • e_p: number of passing tests that cover the element.
  • n_p: number of passing tests that do not cover the element.
  • e_f: number of failing tests that cover the element.
  • n_f: number of failing tests that do not cover the element.

Each array has length num_elements, and element-wise:

e_p + n_p == total number of passing tests
e_f + n_f == total number of failing tests

The tuple order is exactly (e_p, n_p, e_f, n_f).

Fitting and Scores

fit(X, y)

Validate the supplied data, derive its spectrum, compute one suspiciousness score per program element using the selected formula, and store the resulting one-dimensional score array in scores_. The score at index i corresponds to column i of X. Calling fit replaces scores from any previous fit. The established method does not provide a chaining return value.

fit_predict(X, y)

Fit on the supplied data and return the resulting suspiciousness score array. The returned values are the same scores exposed through scores_.

Suspiciousness Formulas

All formulas operate element-wise on (e_p, n_p, e_f, n_f). Higher scores mean greater suspiciousness. The selected names have the following definitions:

Ochiai:
    e_f / sqrt((e_f + n_f) * (e_f + e_p))

Tarantula:
    fail_rate = e_f / (e_f + n_f)
    pass_rate = e_p / (e_p + n_p)
    fail_rate / (fail_rate + pass_rate)

Jaccard:
    e_f / (e_f + n_f + e_p)

RussellRao:
    e_f / (e_f + n_f + e_p + n_p)

Hamann:
    (e_f + n_p - e_p - n_f) / (e_f + n_f + e_p + n_p)

SorensonDice:
    (2 * e_f) / (2 * e_f + e_p + n_f)

Dice:
    (2 * e_f) / (e_f + n_f + e_p)

Kulczynski1:
    e_f / (n_f + e_p)

Kulczynski2:
    e_f * (1 / (e_f + n_f) + 1 / (e_f + e_p)) / 2

In particular, Ochiai uses the number of failing tests in e_f + n_f and the number of covering tests in e_f + e_p, exactly as shown.

Ranking

ranks(method=...)

After fit, return a one-dimensional array containing one 1-based rank for each value in scores_. The output remains in program-element/column order; it is not a reordered list of elements.

Ranks are assigned in descending suspiciousness order:

  • The highest score has rank 1.
  • Lower scores receive lower-priority (numerically larger) ranks.
  • Ties occupy the ordinary sorted rank positions they span, so positions following a tie are skipped as appropriate.

The method argument must support these tie policies:

  • method='min': every member of a tied group receives the smallest rank occupied by that group.
  • method='max': every member receives the largest rank occupied by that group.
  • method='average': every member receives the arithmetic mean of the ranks occupied by that group. Fractional ranks must therefore be representable.

For example, if three elements have scores in column order [s, s, t], where t > s, the results are:

method='min'      -> [2,   2,   1]
method='max'      -> [3,   3,   1]
method='average'  -> [2.5, 2.5, 1]

Ranking must use the fitted suspiciousness scores exactly, including ties; it must not recompute scores using a different outcome polarity or formula.

Return-Value Requirements

Spectrum counts, suspiciousness scores, and ranks must be array-like one-dimensional results supporting per-index access and element-wise operations. NumPy arrays are appropriate. Every such result has one entry per program element.

Background: Spectrum-Based Scoring

These formulas compute a suspiciousness score for each program element (e.g., each statement / column) from a coverage matrix X and an outcome vector y. For each element, four counts are derived from the rows of X and the corresponding entries in y:

  • e_f (a.k.a. ef): number of failing runs that execute the element.
  • e_p (a.k.a. ep): number of passing runs that execute the element.
  • n_f (a.k.a. nf): number of failing runs that do NOT execute the element.
  • n_p (a.k.a. np): number of passing runs that do NOT execute the element.

Each formula maps these four counts to a single score per element. The scores for all elements are exposed via the fitted estimator's scores_ attribute (a sequence indexed by element position).
