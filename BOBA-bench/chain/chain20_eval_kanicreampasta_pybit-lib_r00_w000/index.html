Multiplication.booth_secondary(A: Bits, B: Bits) -> list[Bits]
  • A and B have the same width n and are interpreted as signed two’s-complement integers. A is the multiplicand and B is the multiplier.
  • The method performs radix-4 modified (secondary) Booth recoding of B.
  • For each recoded group k, it forms the signed term (digit_k * A) << (2*k).
  • Every returned entry is exactly 2*n bits wide and encodes its signed value in two’s complement. Negative values are sign-represented across the complete 2*n-bit field.
  • The trace is ordered from the least-significant recoded group to the most-significant group. After those group terms, the trace includes their accumulated sum as its final entry; this final entry is the 2*n-bit product of A and B.
  • Thus, for an even width n, there are n/2 shifted Booth terms followed by one accumulated product. The required 6-bit cases therefore return four 12-bit entries.

Shifts use a (mode, count) tuple rather than a bare integer:

value << ('l', count)   # logical left
value >> ('l', count)   # logical right
value << ('a', count)   # arithmetic left
value >> ('a', count)   # arithmetic right

The long mode names 'logic' and 'arithmetic' are also accepted in place of 'l' and 'a'. For a non-negative count:

  • Every shift returns a new Bits with the same width as its operand.
  • Logical left shift discards high-order bits and inserts zeros at the low-order/right end. Logical right shift discards low-order bits and inserts zeros at the high-order/left end.
  • Arithmetic right shift behaves as a sign-propagating right shift: newly exposed high positions are filled with the operand's original MSB.
  • Arithmetic left shift keeps the operand's original MSB fixed. The field after that MSB is shifted left and zero-filled on the right.
  • A count of zero returns the same bit sequence. A logical count at least as large as the width produces all zeros.
