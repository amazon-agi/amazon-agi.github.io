Task Specification: Add Image Tag and History Functions

Overview

Add two new functions to the podman.images module: tag_image and history. These functions operate against an API client object that is passed in as the first argument.

API Client Contract

The functions receive an api object (first positional argument). This object provides:

  • A method to perform HTTP requests against image endpoints (the same mechanism already used by existing functions in the module such as remove).
  • api.delete(path) — performs a DELETE-style request to the given path and returns a response object.
  • api.raise_image_not_found(...) — a method that, when invoked, raises podman.errors.ImageNotFound.

The response object returned by API calls exposes:

  • .status — an integer HTTP status code.
  • .read() — returns the response body as bytes.

When an underlying API request targets a nonexistent image, the request raises podman.errors.NotFoundError. In that case, the function must call api.raise_image_not_found(...), which raises podman.errors.ImageNotFound. The net effect is that podman.errors.ImageNotFound propagates out of the function.

Required Functions

podman.images.tag_image(api, name, repo, tag)

Tags an existing image.

  • Parameters:
    • api — the API client object.
    • name — identifier of the source image to tag.
    • repo — the target repository.
    • tag — the target tag.
  • Behavior: Issues the request needed to tag the image via api.
  • Return value: Returns True on success. Success corresponds to the API responding with HTTP status 201.
  • Error condition: If the underlying request raises podman.errors.NotFoundError (image does not exist), the function must invoke api.raise_image_not_found(...), resulting in podman.errors.ImageNotFound being raised.
podman.images.history(api, name)

Retrieves the history of an image.

  • Parameters:
    • api — the API client object.
    • name — identifier of the image.
  • Behavior: Retrieves the image history by calling api.delete('/images/{name}/history') — for an image named foo this must be exactly api.delete('/images/foo/history'), called exactly once.
  • Return value: Reads the response body (bytes) via the response object's .read(), parses it as JSON, and returns the resulting deserialized object. For a response body of b'{"Id": "a"}', the return value is the dict {'Id': 'a'}. A successful response has HTTP status 200.

The following must be available under podman.errors:

  • podman.errors.ImageNotFound — raised when an image is not found.
  • podman.errors.NotFoundError — the lower-level error raised by the API request layer when a resource is not found.

(These already exist in the codebase and are used by existing functions; no new error types need to be defined.)

Module Location

Both functions must be importable as podman.images.tag_image and podman.images.history.
