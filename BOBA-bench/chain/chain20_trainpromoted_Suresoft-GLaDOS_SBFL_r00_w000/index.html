Task Specification: Spectrum-Based Fault Localization (SBFL) Formulas

Overview

Implement a Python module that computes suspiciousness scores for program elements using spectrum-based fault localization (SBFL) formulas. The module must expose two formula classes, Ochiai and Tarantula, that share a common interface for extracting a program spectrum and computing scores.

Module & Public API

Create the module sbfl/formula.py (importable as sbfl.formula), exposing two classes:

  • Ochiai
  • Tarantula

Both classes must be instantiable with no arguments (e.g. Ochiai(), Tarantula()).

Inputs

The methods below accept two arguments:

  • X: a 2-D NumPy boolean array of shape (num_tests, num_elements). Row i, column j is True if program element j was executed (covered) by test case i.
  • y: a 1-D NumPy boolean array of length num_tests. Entry i is True if test case i passed, and False if it failed.

Required Methods

get_spectrum(X, y)

Returns a tuple of four 1-D NumPy arrays, each of length num_elements (the number of columns of X), in this exact order:

(e_p, n_p, e_f, n_f)

For each program element (column) j:

  • e_p[j] = number of passing tests that executed element j.
  • n_p[j] = number of passing tests that did not execute element j.
  • e_f[j] = number of failing tests that executed element j.
  • n_f[j] = number of failing tests that did not execute element j.

Consequently, for every element j:

  • e_p[j] + n_p[j] equals the total number of passing tests (y.sum()).
  • e_f[j] + n_f[j] equals the total number of failing tests ((~y).sum()).

Worked example. Given:

X = [[1, 0, 1],
     [0, 1, 1],
     [1, 1, 0]]   (as bool)
y = [1, 0, 1]      (as bool; 1 = pass, 0 = fail)

the result is:

  • e_p = [2, 1, 1]
  • n_p = [0, 1, 1]
  • e_f = [0, 0, 1]
  • n_f = [1, 1, 0]
fit(X, y)

Computes the suspiciousness score for every program element (column of X) using the formula corresponding to the class, and stores the resulting 1-D NumPy array (length num_elements) in the instance attribute scores_.

If the input contains no failing test case (i.e. every entry of y is True), fit must raise an exception.

scores_ attribute

After a successful call to fit, the instance attribute scores_ holds the computed score array. scores_[j] is the suspiciousness score of element j.

Formula Definitions

Using the spectrum values e_p, n_p, e_f, n_f per element:

Ochiai
score = e_f / sqrt( (e_f + n_f) * (e_f + e_p) )

When the denominator is zero (no coverage by failing tests, or the element is not executed by any failing test), the score for that element must be 0.

Tarantula
score = (e_f / (e_f + n_f)) / ( (e_f / (e_f + n_f)) + (e_p / (e_p + n_p)) )

When the resulting value is undefined (denominators or overall denominator equal to zero), the score for that element must be 0.

Expected Results (worked example)

For the example spectrum above:

  • Ochiai scores: [0, 0, 0.707] (element 2 rounds to 0.707 at 3 decimals).
  • Tarantula scores: [0, 0, 0.667] (element 2 equals 2/3).

Requirements

  • Use NumPy for array operations.
  • Element scores must align by column index with the input X.
