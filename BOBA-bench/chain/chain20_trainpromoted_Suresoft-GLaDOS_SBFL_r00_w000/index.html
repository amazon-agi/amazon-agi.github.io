Task Specification: Formulas for Spectrum-Based Fault Localization (SBFL)

Summary

Build a Python module that calculates suspiciousness scores for program elements by means of spectrum-based fault localization (SBFL) formulas. Two formula classes, Ochiai and Tarantula, must be exposed by the module; they share a common interface for extracting a program spectrum and computing scores.

Module and Public API

Create the module sbfl/formula.py (importable as sbfl.formula), which has the two following exposed classes:

  • Ochiai
  • Tarantula

It must be possible to instantiate both classes with no arguments (e.g. Ochiai(), Tarantula()).

Input Data

Two arguments are accepted by the methods below:

  • X: a 2-D NumPy boolean array with shape (num_tests, num_elements). The entry in row i, column j is True when program element j was executed (covered) by test case i.
  • y: a 1-D NumPy boolean array whose length is num_tests. Entry i is True when test case i passed, and False when it failed.

Required Methods

get_spectrum(X, y)

A tuple of four 1-D NumPy arrays is returned — each of length num_elements (the number of columns of X) — in exactly this order:

(e_p, n_p, e_f, n_f)

For each program element (column) j, the counts are as follows:

  • e_p[j] is the number of passing tests that executed element j.
  • n_p[j] is the number of passing tests that did not execute element j.
  • e_f[j] is the number of failing tests that executed element j.
  • n_f[j] is the number of failing tests that did not execute element j.

As a consequence, for every element j:

  • e_p[j] + n_p[j] is equal to the total number of passing tests (y.sum()).
  • e_f[j] + n_f[j] is equal to the total number of failing tests ((~y).sum()).

A worked example. Take:

X = [[1, 0, 1],
     [0, 1, 1],
     [1, 1, 0]]   (as bool)
y = [1, 0, 1]      (as bool; 1 = pass, 0 = fail)

the outcome is:

  • e_p = [2, 1, 1]
  • n_p = [0, 1, 1]
  • e_f = [0, 0, 1]
  • n_f = [1, 1, 0]
fit(X, y)

The suspiciousness score is computed for every program element (column of X) with the formula that corresponds to the class, and the resulting 1-D NumPy array (of length num_elements) is stored in the instance attribute scores_.

fit must raise an exception if the input contains no failing test case (i.e. every entry of y is True).

scores_ attribute

After fit has been called successfully, the computed score array is held by the instance attribute scores_. scores_[j] is the suspiciousness score of element j.

Formula Definitions

Working from the per-element spectrum values e_p, n_p, e_f, n_f:

Ochiai
score = e_f / sqrt( (e_f + n_f) * (e_f + e_p) )

Whenever the denominator comes out as zero (no coverage by failing tests, or the element is not executed by any failing test), the score for that element must be 0.

Tarantula
score = (e_f / (e_f + n_f)) / ( (e_f / (e_f + n_f)) + (e_p / (e_p + n_p)) )

If the resulting value is undefined (denominators or the overall denominator equal to zero), the score for that element must be 0.

Expected Results for the Worked Example

For the spectrum shown above in the example:

  • Ochiai scores: [0, 0, 0.707] (element 2 comes out to 0.707 when rounded to 3 decimals).
  • Tarantula scores: [0, 0, 0.667] (element 2 is equal to 2/3).

Requirements

  • Carry out array operations with NumPy.
  • The scores of elements must line up by column index with the input X.

  • ep: the count of passing tests that executed element i

score = ef / total
Hamann

score = (ef + np - ep - nf) / total

These values confirm the formulas stated above:

  • The RussellRao score of 1/3 corresponds to ef=1, total=3+... such that ef/total = 1/3.
