Function Specifications

zpadlist(intlist, type, minval, maxval)

Validates and zero-pads a list of integers.

  • Parameters:
    • intlist: a list of integers.
    • type: a string label describing the kind of values (e.g. 'days').
    • minval: the minimum allowed integer value (inclusive).
    • maxval: the maximum allowed integer value (inclusive).
  • Behavior:
    • If every integer in intlist lies within the inclusive range [minval, maxval], return a new list where each integer is converted to a string, zero-padded to a minimum width of 2 characters (e.g. 1 → '01', 12 → '12'). The order of the input list is preserved.
    • If any integer in intlist is outside the inclusive range [minval, maxval], raise an exception.
zpad_days(intlist)

Validates and zero-pads a list of day values.

  • Parameters:
    • intlist: a list of integers.
  • Behavior:
    • Valid values are integers in the inclusive range [1, 31].
    • If all values are valid, return a new list where each integer is converted to a string, zero-padded to a minimum width of 2 characters, preserving input order.
    • If any value falls outside [1, 31], raise an exception.
zpad_months(intlist)

Validates and zero-pads a list of month values.

  • Parameters:
    • intlist: a list of integers.
  • Behavior:
    • Valid values are integers in the inclusive range [1, 12].
    • If all values are valid, return a new list where each integer is converted to a string, zero-padded to a minimum width of 2 characters, preserving input order.

  • Parameters:
    • intlist: a list of integers.
  • Behavior:
    • Valid values are integers in the inclusive range [0, 23].
