1. Covariance-matrix de-noising

Inputs and return value

de_noise_covariance_matrix(covariance_matrix, q, bandwidth) accepts:

  • covariance_matrix: a square N x N NumPy covariance array. Inputs may be assumed to be valid covariance matrices with usable positive diagonal entries. The reference input has shape (20, 20).
  • q: a floating-point observations-to-variables ratio, T / N.
  • bandwidth: a floating-point bandwidth for the kernel-density estimate of the empirical eigenvalue distribution.

Return a NumPy array with the same shape as covariance_matrix. For a valid covariance input, the result must be symmetric, retain the input variances on its diagonal, and represent the de-noised covariance.

Required transformation

Let S be the input covariance matrix.

  1. Convert covariance to correlation. Save the original standard deviations

    std_i = sqrt(S_ii)

    and form

    R_ij = S_ij / (std_i * std_j).

  2. Compute the correlation eigensystem. Perform the symmetric eigenvalue decomposition of R and order the eigenvalue/eigenvector pairs from largest to smallest:

    R = V diag(lambda) V.T,
lambda_0 >= lambda_1 >= ... >= lambda_(N-1).

  3. Fit the Marchenko-Pastur noise boundary. Fit the scale/variance parameter of a Marchenko-Pastur distribution to the empirical correlation eigenvalues by minimizing the squared discrepancy between its density and a Gaussian kernel-density estimate whose bandwidth is bandwidth. For a candidate variance var, use the support

    lambda_minus = var * (1 - sqrt(1 / q))**2
lambda_plus  = var * (1 + sqrt(1 / q))**2

    and, on that support, the density

    p(x) = q * sqrt((lambda_plus - x) * (x - lambda_minus))
       / (2 * pi * var * x).

    A fit based on 1,000 evenly spaced support points, a variance search in [1e-5, 1 - 1e-5] beginning at 0.5, and a fallback variance of 1 when fitting does not converge defines the reference numerical procedure. Numerically equivalent fitting is acceptable. The fitted lambda_plus is the maximum noise eigenvalue. Eigenvalues greater than this boundary are signal; eigenvalues at or below it are noise. Both q and bandwidth must participate in this fitting and classification.

  4. Collapse the pre-normalization noise spectrum. Preserve every signal eigenvalue. Replace every noise eigenvalue by the arithmetic mean of all eigenvalues classified as noise:

    noise_mean = mean(lambda_i for lambda_i <= lambda_plus)
lambda_tilde_i = lambda_i      if lambda_i > lambda_plus
                 noise_mean    otherwise.

    Reconstruct the intermediate matrix

    R_raw = V diag(lambda_tilde) V.T.

  5. Re-normalize after reconstruction. This step is mandatory. Convert R_raw to a unit-diagonal correlation matrix rather than treating R_raw itself as the final correlation matrix:

    R_denoised_ij = R_raw_ij / sqrt(R_raw_ii * R_raw_jj).

    In particular, returning R_raw directly after the common-eigenvalue replacement does not satisfy the required behavior. The re-normalization preserves the correlation interpretation and can make the final matrix's eigenvalues distinct even though the noise eigenvalues were equal before this step.

  6. Restore the original covariance scale. Return

    S_denoised_ij = R_denoised_ij * std_i * std_j.

    Thus the result has the input covariance's original diagonal exactly up to floating-point precision.

2. Error estimators

Common input contract

Both estimator classes expose:

estimate(mu, cov, allocation, optimal_allocation) -> float

where:

  • mu is a one-dimensional NumPy expected-return vector of length N;
  • cov is an N x N NumPy covariance matrix;
  • allocation is a one-dimensional candidate portfolio-weight vector of length N; and
  • optimal_allocation is a one-dimensional reference portfolio-weight vector of length N.

Each method returns a scalar floating-point error. The common signature is intentional: ExpectedOutcomeErrorEstimator accepts cov even though its formula does not use it, and VarianceErrorEstimator accepts mu even though its formula does not use it.

ExpectedOutcomeErrorEstimator

Return the reference allocation's expected outcome minus the candidate allocation's expected outcome:

error = dot(mu, optimal_allocation) - dot(mu, allocation)
      = dot(mu, optimal_allocation - allocation).

The subtraction direction is significant. A positive result means the reference allocation has the higher expected return. Do not return candidate outcome minus reference outcome.

VarianceErrorEstimator

Let

delta = allocation - optimal_allocation.

Return the covariance-weighted squared allocation deviation, equivalently the variance of the difference portfolio:

error = delta.T @ cov @ delta.

This is not the difference between the two portfolios' individual variances. For a positive-semidefinite covariance matrix, this value is nonnegative apart from possible floating-point roundoff.

Overview

  • Constructor parameters:

    • n_observations: an integer number of observations (passed positionally).
  • transform(): takes no additional arguments and returns the de-noised covariance matrix as a 2D NumPy array of shape (N, N).

Both interfaces must produce the identical de-noising result for the same inputs.

Required Behavior

Given a sample covariance matrix and the number of observations, the de-noising procedure must:

  1. Convert the covariance matrix to a correlation matrix.
  2. Perform an eigenvalue decomposition of the correlation matrix.
  3. Compute the ratio q = n_observations / N (where N is the number of variables / matrix dimension) and use it, together with the empirical eigenvalue distribution, to determine the Marchenko–Pastur noise threshold. This threshold separates "signal" eigenvalues from "noise" eigenvalues.
  4. Replace all eigenvalues below the threshold (the noise eigenvalues) with their average value, while preserving the eigenvalues above the threshold (the signal eigenvalues). The total trace (sum of eigenvalues) must be preserved.
  5. Reconstruct the correlation matrix from the modified eigenvalues and the original eigenvectors, ensuring the diagonal remains unit (i.e., re-normalized to a valid correlation matrix).
  6. Convert the de-noised correlation matrix back to a covariance matrix using the original standard deviations (square roots of the original diagonal variances).

The output is a symmetric covariance matrix of the same dimension as the input.

  • mu is either a one-dimensional NumPy array of length N or None.
  • Return a one-dimensional NumPy array of length N, in the same asset order as the inputs.
Closed-form portfolio solve

Every intra-cluster and inter-cluster portfolio must use the same unconstrained analytic solve. Given covariance matrix Sigma and objective vector r, calculate:

v = Sigma⁻¹ r
w = v / (1ᵀ v)

Equivalently:

w = Sigma⁻¹ r / (1ᵀ Sigma⁻¹ r)

A mathematically equivalent linear solve may be used. Do not replace this contract with a long-only optimizer or another constrained numerical portfolio solver.

  • In maximum-Sharpe mode, r is the applicable expected-return vector. This is the zero-risk-free-rate tangency solution.
  • In minimum-variance mode, r is a vector of ones of the applicable dimension.
  • The solve is unconstrained, so negative weights and short positions are permitted.
  • The normalization is required at both optimization levels. Consequently, the unrounded final portfolio weights sum to 1 up to ordinary floating-point error; there is no non-negativity requirement.
Deterministic clustering

Clustering must be recomputed for every call to allocate as follows:

  1. Convert cov to a correlation matrix corr using cov_to_corr.

  2. Form the N × N feature matrix

    X = np.sqrt((1 - corr) / 2)

    Each asset is represented by the corresponding row of X; K-Means uses ordinary Euclidean distance between those rows. This is not passed as a precomputed-distance metric.

  3. Consider every candidate cluster count k from 2 through min(10, N - 1), inclusive.

  4. For each candidate, fit K-Means to X using standard k-means++ initialization, exactly n_init=10, and random_state=42.

  5. Compute the individual Euclidean silhouette coefficients for that candidate partition. Score the candidate by:

    mean(silhouette coefficients) / standard_deviation(silhouette coefficients)

  6. Select the partition with the greatest score. If scores tie, retain the smaller candidate cluster count. Use that selected partition for both allocation levels; do not select clusters from mu.

The fixed seed, initialization count, feature representation, candidate range, and silhouette-statistic selection rule are part of the required behavior. Calling allocate repeatedly with the same inputs must produce the same result. Calling it with other inputs in between must not affect that result: no selected cluster count, labels, or other clustering state may carry over from an earlier allocation.

Nested Clustered Optimization steps

Let the selected partition contain K clusters.

  1. Intra-cluster allocations

    For each cluster c, let I_c be its asset indices. Apply the closed-form portfolio solve to:

    • cov[np.ix_(I_c, I_c)], and
    • mu[I_c] when mu is provided, otherwise a ones vector.

    Place the resulting cluster weights in their original asset positions. Collect all intra-cluster portfolios as the columns of an N × K matrix W_intra; entries outside a column's cluster are zero. Every column is normalized to sum to 1.

  2. Reduced inter-cluster problem

    Construct the cluster-level covariance matrix:

    cov_inter = W_intraᵀ cov W_intra

    If mu is provided, construct cluster-level expected returns as:

    mu_inter = W_intraᵀ mu

    Apply the same closed-form solve to cov_inter, using mu_inter in maximum-Sharpe mode or a length-K ones vector in minimum-variance mode. This produces the normalized inter-cluster weights w_inter.

  3. Final asset allocation

    Return:

    weights = W_intra w_inter

    Flatten the result to a one-dimensional array while preserving the original asset order.

Allocation modes
  • mu is not None — maximum-Sharpe mode: use expected returns at both the intra-cluster and inter-cluster levels.
  • mu is None — minimum-variance mode: replace expected returns by ones at both levels and optimize from covariance information alone.
