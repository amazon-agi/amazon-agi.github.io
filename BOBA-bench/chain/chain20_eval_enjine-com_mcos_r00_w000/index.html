1. De-noising of the covariance matrix

Inputs and return value

The de_noise_covariance_matrix(covariance_matrix, q, bandwidth) function accepts:

  • covariance_matrix: a square N x N covariance array in NumPy. It may be assumed that inputs are valid covariance matrices with usable positive diagonal entries. The reference input has the shape (20, 20).
  • q: a floating-point ratio of observations to variables, T / N.
  • bandwidth: a floating-point bandwidth used by the kernel-density estimate of the empirical eigenvalue distribution.

Return a NumPy array of the same shape as covariance_matrix. For a valid covariance input, the result must be symmetric, preserve the input variances on its diagonal, and represent the de-noised covariance.

Required transformation

Denote the input covariance matrix by S.

  1. Convert the covariance into a correlation. Record the original standard deviations

    std_i = sqrt(S_ii)

    and build

    R_ij = S_ij / (std_i * std_j).

  2. Compute the correlation eigensystem. Carry out the symmetric eigenvalue decomposition of R and arrange the eigenvalue/eigenvector pairs from largest to smallest:

    R = V diag(lambda) V.T,
lambda_0 >= lambda_1 >= ... >= lambda_(N-1).

  3. Fit the Marchenko-Pastur noise boundary. Fit the scale/variance parameter of a Marchenko-Pastur distribution to the empirical correlation eigenvalues by minimizing the squared discrepancy between its density and a Gaussian kernel-density estimate with bandwidth as its bandwidth. Given a candidate variance var, use the support

    lambda_minus = var * (1 - sqrt(1 / q))**2
lambda_plus  = var * (1 + sqrt(1 / q))**2

    and, restricted to that support, the density

    p(x) = q * sqrt((lambda_plus - x) * (x - lambda_minus))
       / (2 * pi * var * x).

    The reference numerical procedure is defined by a fit based on 1,000 evenly spaced support points, a variance search in [1e-5, 1 - 1e-5] starting at 0.5, and a fallback variance of 1 for cases where fitting does not converge. Fitting that is numerically equivalent is acceptable. The fitted lambda_plus serves as the maximum noise eigenvalue. An eigenvalue greater than this boundary is signal; an eigenvalue at or below it is noise. Both q and bandwidth must take part in this fitting and classification.

  4. Collapse the pre-normalization noise spectrum. Keep every signal eigenvalue. Substitute every noise eigenvalue with the arithmetic mean of all eigenvalues classified as noise:

    noise_mean = mean(lambda_i for lambda_i <= lambda_plus)
lambda_tilde_i = lambda_i      if lambda_i > lambda_plus
                 noise_mean    otherwise.

    Rebuild the intermediate matrix

    R_raw = V diag(lambda_tilde) V.T.

  5. Re-normalize after reconstruction. Performing this step is mandatory. Convert R_raw into a unit-diagonal correlation matrix instead of treating R_raw itself as the final correlation matrix:

    R_denoised_ij = R_raw_ij / sqrt(R_raw_ii * R_raw_jj).

    In particular, directly returning R_raw after the common-eigenvalue replacement does not satisfy the required behavior. The re-normalization maintains the correlation interpretation and can make the eigenvalues of the final matrix distinct even though the noise eigenvalues were equal before this step.

  6. Restore the original covariance scale. Return

    S_denoised_ij = R_denoised_ij * std_i * std_j.

    Consequently, the result carries the input covariance's original diagonal exactly, up to floating-point precision.

2. Error estimators

Shared input contract

Both of the estimator classes expose:

estimate(mu, cov, allocation, optimal_allocation) -> float

in which:

  • mu is a one-dimensional NumPy vector of expected returns with length N;
  • cov is a NumPy covariance matrix of size N x N;
  • allocation is a one-dimensional vector of candidate portfolio weights with length N; and
  • optimal_allocation is a one-dimensional vector of reference portfolio weights with length N.

Every method returns a scalar floating-point error. The shared signature is deliberate: ExpectedOutcomeErrorEstimator accepts cov even though its formula does not use it, and VarianceErrorEstimator accepts mu even though its formula does not use it.

ExpectedOutcomeErrorEstimator

Return the expected outcome of the reference allocation minus the expected outcome of the candidate allocation:

error = dot(mu, optimal_allocation) - dot(mu, allocation)
      = dot(mu, optimal_allocation - allocation).

The direction of the subtraction is significant. A positive result indicates that the reference allocation has the higher expected return. Do not return the candidate outcome minus the reference outcome.

VarianceErrorEstimator

Define

delta = allocation - optimal_allocation.

Return the covariance-weighted squared deviation between the allocations, equivalently the variance of the difference portfolio:

error = delta.T @ cov @ delta.

This is not obtained by subtracting the two portfolios' individual variances. When the covariance matrix is positive-semidefinite, this value is nonnegative apart from possible floating-point roundoff.

Overview

2. Module: mcos.covariance_transformer

    def __init__(self, covariance_matrix, n_observations):
        ...

    def transform(self):
        ...
  • Constructor parameters:
    • covariance_matrix: a square 2D NumPy array of shape (N, N).
    • n_observations: the number of observations, as an integer (passed positionally).
  • transform(): takes no additional arguments; it returns the de-noised covariance matrix as a 2D NumPy array of shape (N, N).

For the same inputs, both interfaces must produce the identical de-noising result.

Behavior Requirements

When supplied with a sample covariance matrix and the number of observations, the de-noising procedure must:

  1. Convert the covariance matrix into a correlation matrix.
  2. Run an eigenvalue decomposition on that correlation matrix.
  3. Compute the ratio q = n_observations / N (where N denotes the number of variables / matrix dimension) and, using it together with the empirical eigenvalue distribution, determine the Marchenko–Pastur noise threshold. This threshold is what separates "signal" eigenvalues from "noise" eigenvalues.
  4. Replace all eigenvalues below the threshold (the noise eigenvalues) with their average value, keeping the eigenvalues above the threshold (the signal eigenvalues) intact. The total trace (the sum of the eigenvalues) must be preserved.
  5. Rebuild the correlation matrix from the modified eigenvalues together with the original eigenvectors, ensuring the diagonal remains unit (i.e., re-normalized to a valid correlation matrix).
  6. Map the de-noised correlation matrix back to a covariance matrix, using the original standard deviations (the square roots of the original diagonal variances).

The result is a symmetric covariance matrix with the same dimension as the input.

1. Correlation-distance representation

Form the correlation matrix C from cov:

C[i, j] = cov[i, j] / sqrt(cov[i, i] * cov[j, j])

D[i, j] = sqrt((1 - C[i, j]) / 2)

Each row of D serves as the feature vector of one asset. Silhouette and K-means calculations work on these rows with ordinary Euclidean feature-space distance; D is not passed in as a precomputed pairwise-distance metric.

2. Deterministic selection of clusters

The asset partition must be selected by following this exact search protocol:

  1. Take the maximum candidate cluster count to be floor(n / 2).
  2. Carry out 10 complete search passes. Within every pass, work through the candidate cluster counts in ascending order, from 2 through floor(n / 2), inclusive.
  3. For each candidate count, run K-means a single time (n_init=1) with k-means++ initialization, standard Lloyd-style Euclidean K-means, at most 300 iterations, and tolerance 1e-4. As a result, over the complete search, each candidate count is initialized 10 times.
  4. At the start of every allocate call, create a fresh deterministic random-state stream with seed 33. Drive the successive K-means runs in the pass/candidate order above from that same advancing stream; do not restart the seed for each candidate.
  5. For every candidate clustering, compute the silhouette value of each row of D, then score the candidate as:
mean(silhouette values) / population_stddev(silhouette values)
  1. Keep the candidate that attains the greatest score. Comparisons are strict, so a tying score does not replace the earlier candidate.

On every call, the number of clusters and the complete partition are computed anew. They must not be stored or carried over from call to call, even when the same NCOOptimizer instance is reused. w = (Σ⁻¹ r) / (1ᵀ Σ⁻¹ r)

In minimum-variance mode, substitute 1 for r, which gives:

w = (Σ⁻¹ 1) / (1ᵀ Σ⁻¹ 1)

This is an analytic unconstrained allocation: do not impose long-only constraints, weight bounds, or numerical weight cleaning. Each portfolio this formula produces is normalized to sum to 1; individual weights may be negative.

  • If mu is supplied, extract the expected-return subvector r_j matching that cluster; otherwise use an all-ones vector.
  • Apply the analytic formula above to obtain the intra-cluster weight vector of that cluster.

5. Inter-cluster stage and final weights

Collapse the clusters down to k synthetic assets:

Σ_cluster = Wᵀ cov W
r_cluster = Wᵀ mu                 # only when mu is supplied

That same analytic formula is then applied to Σ_cluster and r_cluster. In minimum-variance mode, a k-entry all-ones vector is used in place of the synthetic expected returns. If the resulting inter-cluster vector is w_cluster, return:

w_final = W w_cluster

Therefore, the final weights sum to 1 up to floating-point roundoff. They are not long-only and can contain negative entries.

  5. Swap all noise eigenvalues for their average value, leaving the signal eigenvalues unchanged.
  6. Rebuild the correlation matrix, using the modified eigenvalues together with the original eigenvectors.
  7. Turn the de-noised correlation matrix back into a covariance matrix, making use of the original variances.

Procedure for the HRP Allocation

What follows is the procedure that HRPOptimizer.allocate must follow.

  1. Turn the covariance into a correlation matrix. The conversion is performed with mcos.covariance_transformer.cov_to_corr(cov).

  2. Form the correlation distances. Compute

    [ d_{i,j}=\sqrt{\frac{1-\rho_{i,j}}{2}}. ]

    The diagonal of the distance matrix must be explicitly set to zero, so that floating-point residuals have no effect on the clustering.

  3. Carry out the hierarchical clustering. SciPy single-linkage clustering is applied, with the square distance matrix passed directly to:

    scipy.cluster.hierarchy.linkage(distance_matrix, method="single")

    The linkage observation matrix is, by design, the square matrix itself. It must not first be converted into condensed-distance form.

  4. Quasi-diagonalize the linkage. The starting point is the pair of children belonging to the final combined linkage node. Then, recursively, every non-leaf node is replaced by its first child followed by its second child. Read from left to right, the leaf sequence that results is the quasi-diagonal order.

  5. Compute a cluster's variance. Given any cluster, select its covariance submatrix C_c and form inverse-variance weights from that submatrix's diagonal,

    [ u_i=\frac{1/C_{c,ii}}{\sum_j 1/C_{c,jj}}, ]

    then compute

    [ V_c=u^\mathsf{T}C_cu. ]

  6. Bisect recursively. Each ordered leaf sequence is divided into two halves by means of NumPy-style array splitting; as a result, when the number of leaves is odd, the extra element ends up in the left half. Given left and right cluster variances V_L and V_R, apply

    [ \alpha_L=1-\frac{V_L}{V_L+V_R}=\frac{V_R}{V_L+V_R}, \qquad \alpha_R=1-\alpha_L. ]

    The weights that each subtree computes recursively are multiplied by that subtree's allocation factor, and the left result is concatenated before the right one.

The array that is returned itself follows the quasi-diagonal leaf sequence. Remapping it to the original column order of the covariance matrix must not happen.

  • Renaming must not be applied to existing public class and function names.
  • The behavior of the existing Markowitz optimizer does not change.
  • Apart from the pseudoinverse support in its internal portfolio calculations, NCO's established clustering policy stays as it is.
  • Optimizer outputs continue to be flat NumPy arrays; simulated means must not be returned in the form of column vectors.
  • Covariance denoising is opt-in, and the simulated covariance that is passed through the supplied transformer sequence is the only thing it affects.
  • HRP must not use expected returns, must not remap its quasi-diagonal output, must not convert its square clustering input into condensed form, and must not hard-code allocations for particular data sets.
  • Risk parity must use the covariance, target risk budget, and initial weights that the caller supplies rather than hard-coded allocations; expected returns have no effect on it.
  • Behavior in the presence of malformed or non-square covariance matrices, zero-variance assets, incompatible vector lengths, invalid risk budgets, or infeasible initial risk-parity weights lies outside the required scope.
