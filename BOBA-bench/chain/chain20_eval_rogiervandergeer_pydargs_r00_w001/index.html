You are working on pydargs, a library that parses command-line arguments into dataclass instances. The public entry point is:

from pydargs import parse

parse(config_class, args) takes a dataclass type and a list of string arguments, and returns an instance of that dataclass with fields populated from the parsed arguments.

Your task is to implement correct handling of list and sequence typed fields.

Required Behavior

Supported field types

Fields annotated with the following generic types must be parseable from the command line:

  • list[T] (e.g. list[int], list[str], list[float])
  • collections.abc.Sequence[T] (e.g. Sequence[float], Sequence[str])

For both, T is the element type. Each element of the field value must be converted to T.

Argument consumption

A list/sequence field named arg is provided on the command line via the flag --arg followed by one or more whitespace-separated values. All values following the flag (until the next flag or end of arguments) are collected, each converted to the element type T, and stored as a Python list of converted elements.

This applies to both list[T] and Sequence[T] annotations: the resulting field value is always a list, even when the annotation is Sequence and/or when the default was a tuple.

Defaults

  • When the corresponding flag is not supplied on the command line, the field takes its declared default value unchanged (i.e. a tuple default remains a tuple; a list default remains a list). No element conversion is applied to defaults.
  • A list/sequence field with no default is a required argument. If it is not supplied, parsing must fail by exiting the program (raising SystemExit), and an error message must be printed to standard error containing:
    the following arguments are required: --<name>
Type conversion and errors
  • Each supplied value is converted to the element type T.
  • If a supplied value cannot be converted to the element type, parsing must fail by exiting the program (SystemExit), and an error message must be printed to standard error in the form:
    error: argument --<name>: invalid <type> value:
    where <type> is the name of the element type (e.g. float).
