Overview

Implement a Server class that represents a network server endpoint, constructible either from a full URI or from individual components (host, port, scheme). The class must validate its inputs and expose accessor methods.

  2. From components — when host, port, and scheme are provided.

Both modes may be combined (all four arguments supplied), in which case the component values must be consistent with the values parsed from the URI.

URI Format Requirements

A valid URI must have the form:

<scheme>://<host>:<port>[/<optional path>]

Where:

  • <scheme> must be present and must be http or https (case-insensitive).
  • The scheme must be followed by exactly :// — i.e., exactly two slashes after the colon. Fewer than two slashes (e.g. http:/host:port) or more than two slashes (e.g. http:///host:port) is invalid.
  • <host> must be present.
  • Exactly one colon separates host and port. Multiple consecutive colons before the port (e.g. host::port) is invalid.
  • <port> must be present and non-empty (a URI ending immediately after the port colon, e.g. https://host:, is invalid; a URI with no port colon at all, e.g. https://host, is invalid).
  • An optional path may follow the port (e.g. http://host:port/account/saved); this is valid and is ignored for host/port extraction.

Any input that does not conform to this format must cause the constructor to raise an exception. This includes:

  • A URI missing the scheme entirely (e.g. 127.0.0.1:56747).
  • Arbitrary text that is not a URI, whether or not it contains a colon (e.g. this is a spam, this is a spam:).
Component Construction

When constructing from host, port, and scheme (with port given as an integer and scheme given as a string such as "https"), the object must be created successfully and expose the given host and port.

Consistency Validation

When both a uri and one or more of host, port, or scheme are supplied, each supplied component must match the corresponding value parsed from the URI. If any supplied component contradicts the URI's parsed value, the constructor must raise an exception. This applies independently to host mismatch, port mismatch, and scheme mismatch.

Accessor Methods
