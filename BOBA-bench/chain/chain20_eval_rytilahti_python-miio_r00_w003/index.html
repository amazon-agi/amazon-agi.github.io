ToiletlidStatus

Construction and raw input

A single dictionary holding the raw device state is passed to ToiletlidStatus at construction. Its logical status is built from these fields:

  • work_state — an integer code for the device work state.
  • ambient_light — the name of the current color, as a string.
  • filter_use_flux — the remaining filter percentage as a string that carries no percent sign.
  • filter_use_time — the remaining filter time, as a string.

A complete raw snapshot may additionally contain an is_on Boolean or other keys that are unrelated.   • filter_remaining_time: returns the raw filter_use_time value with no change.

  • Two instances built from raw dictionaries that are equal must have representations that are equal.
  • Two instances that expose the same status values must also have equal representations even if one raw dictionary contains extra keys and the other does not.

  1. work_state
  2. ambient_light
  3. filter_use_flux

  • Filter percentage display appends % and does not otherwise transform the raw value.
  • The status representation is built only from the exposed logical fields and is unaffected by extra raw snapshot data.
