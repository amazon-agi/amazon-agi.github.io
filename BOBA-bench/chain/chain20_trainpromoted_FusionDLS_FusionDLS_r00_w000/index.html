Required Behavior

file_read(filename)
  • Accepts a filesystem path (a pathlib.Path or path-like) pointing to a pickle file.
  • Returns a nested, dictionary-like structure loaded from that pickle.
  • Indexing the returned object by a design key (e.g. "V10") yields a mapping of sub-region keys to geometry data.
  • Indexing that sub-mapping by a region key (e.g. "ou") yields a geometry mapping d that supports item access (d["key"]) for at least the following keys:
    • "S" — 1D array of parallel distances along the field line.
    • "Btot" — 1D array of total magnetic field magnitude along the field line, same length as "S".
    • "Sx" — scalar parallel distance at the X-point.
    • "Xpoint" — integer index into "S" (and other arrays) marking the X-point location.
LfuncN
  • A callable representing a nitrogen cooling curve, suitable to be passed as the "Lfunc" entry in the solver constants dictionary.
run_dls(constants, radios, d, s_parallel, control_variable=...)

Runs the Detachment Location Sensitivity solver.

Parameters:

  • constants: a dictionary of physical constants. For this task it will contain the keys:
    • "gamma_sheath" (float)
    • "Tt" (float)
    • "qpllu0" (float)
    • "nu" (float)
    • "nu0" (float)
    • "cz0" (float)
    • "Lfunc" (a cooling-curve callable such as LfuncN)
  • radios: a dictionary of boolean flags. For this task it will contain:
    • "ionisation" (bool)
    • "upstreamGrid" (bool)
  • d: a geometry mapping as returned by indexing the structure from file_read (see keys above).
  • s_parallel: a 1D array of parallel front-position values at which to evaluate the solver. These values range from 0 to the parallel distance just below the X-point (d["S"][d["Xpoint"] - 1]).
  • control_variable: keyword argument; for this task it takes the value "density".

Return value:

  • A mapping (dictionary-like) that supports item access.
  • Must contain the key "cvar", whose value is a 1D array of the control-variable values corresponding to each entry of s_parallel.

Correctness Requirement

For the density control variable, the normalized control variable — computed as result["cvar"] / result["cvar"][0] — must closely match the analytic solution.

The analytic reference at each front position s is computed via:

CfInt(d["S"], d["Btot"], d["Sx"], np.max(d["S"]), s)

evaluated over all s in s_parallel, then normalized by dividing the whole array by its first element.

The root-mean-square of the element-wise difference between the normalized control variable and the normalized analytic array must be small (only a few percent).

Notes

  • The solver must work end-to-end using the low-level dictionary/array interface described above; no dedicated input-object or geometry-object classes are required by this task.
