Background / Existing Behavior (assumed present)

You are adding query methods and extending the model's repr.

Required New Methods

TerraModel.has_lookup_tables(self) -> bool

Returns a boolean indicating whether the model currently has lookup tables attached.

  • After lookup tables have been added via add_lookup_tables(...), this returns True.
TerraModel.get_lookup_tables(self)

Returns the lookup tables object currently attached to the model.

  • After lookup tables have been added via add_lookup_tables(some_multitables), this method returns exactly that same object (it must compare equal to the object that was passed to add_lookup_tables).

Input global vector Output vector

Overview

TerraModel(lon=<sequence>, lat=<sequence>, r=<sequence>, fields={<name>: <array>})

The number of lateral grid nodes is the length of lon (equivalently lat), and the number of radii is the length of r.

north  = (-sin(φ) cos(λ), -sin(φ) sin(λ),  cos(φ))
west   = ( sin(λ),        -cos(λ),         0     )
radial = ( cos(φ) cos(λ),  cos(φ) sin(λ),  sin(φ))

For each Cartesian vector v, the geographic result is

(dot(v, north), dot(v, west), dot(v, radial))
