  • Sends the network command over the serial connection.

The write must be a single call carrying the encoded network command.
  • Reads the device's response (a single read returning the full multi-line response text).
  • Parses the response and returns a list of node objects (see below).

Response Format

The response is a block of text of the following form:

  Network:
  --- start list ---
  node|addr|type    |ptcl|cerr|prnt|asso|stts|stat|cntdwn|%dbt|trgt|cval|snsr|ovrl|capin |capout|tree|temp|info
  1   |1   |BOX     |9   |0   |0   |0   |0x00|AUTO|0     |58  |30  |30  |0   |255 |235   |3760  |0x01|0   |AUTO:0(0)

  34  |132 |UCRH    |255 |0   |1   |1   |0x00|-   |0     |-   |-   |-   |59  |-   |-     |-     |-   |209 |-
  --- end list ---

Key characteristics:

  • Fields on each line are separated by the pipe character |.
  • Fields may contain surrounding whitespace that must be stripped.
  • There is a header line (starting with node|addr|type|...) that labels the columns and must not be treated as a data node.
  • There are delimiter/marker lines (Network:, --- start list ---, --- end list ---) that must not be treated as data nodes.
  • Each data line describes one node. The first field is the node number and the second field is the node address.

Node Objects

Each parsed data line must produce a node object. The list returned by get_nodes() must contain these node objects in the same order as they appear in the response.

Each node object must expose (at minimum) these attributes:

  • number: the first field of the data line, as a stripped string.
  • address: the second field of the data line, as a stripped string.

Both values are kept as strings (not converted to integers).

Expected Parsing Result

For the sample response above, get_nodes() must return a list of three node objects with:

Index number address
0 '1' '1'
1 '2' '102'
2 '34' '132'

Edge Cases / Notes

  • Only genuine data rows become nodes; header and marker lines are excluded.
  • Leading/trailing whitespace within each field must be removed so that '1 ' becomes '1', '132 ' becomes '132', etc.
  • The order of nodes in the returned list must match the order in the input text.
