Task Specification: Implement divider Element

Objective

Implement a divider function that produces an HTML <div> element styled as a UI divider.

Public API

Create the function accessible via the following import path:

from shiny_semantic.elements import divider
Function Signature
def divider(*args, **kwargs):
    ...

The function accepts positional child content (e.g., strings) and returns an HTML element object.

Required Behavior

  • Calling divider("Hello") must produce a <div> element whose rendered HTML opening tag is exactly:

    <div class="ui divider">

  • The class attribute value must be exactly ui divider — the words ui and divider separated by a single space, with no leading, trailing, or doubled whitespace.

  • The provided positional content (e.g., "Hello") is passed into the element as its child content.

Notes

  • The returned object must render to HTML such that the opening tag string above appears within the rendered output.
  • No additional attributes or classes beyond ui divider should be present on the element when called as shown.
