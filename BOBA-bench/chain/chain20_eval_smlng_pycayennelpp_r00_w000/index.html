Overview

You are working with the cayennelpp package, which provides classes to construct and parse CayenneLPP-formatted data frames. This task involves modifying the public API of the LppFrame class so that its collection of data entries is exposed as a public attribute rather than via a method call.

Required Change

The LppFrame class (importable as from cayennelpp.lpp_frame import LppFrame) must expose its collection of contained data entries through a public attribute named data.

Specifically:

  • Accessing frame.data on an LppFrame instance must return the collection of data entries currently held by the frame, as a value that supports len().
  • This must be a plain attribute access — frame.data — not a method call. Any prior method-based access (e.g. frame.data()) must no longer be the interface; the collection is obtained directly as an attribute.

Behavior That Must Be Preserved

All existing frame behavior must continue to work, with data now being an attribute:

  1. Empty frame: A newly constructed LppFrame() must have len(frame.data) == 0, and frame.bytes() must return an empty byte sequence.

  2. Construction from bytes: LppFrame.from_bytes(b) must parse a byte sequence into the appropriate number of data entries. For a byte sequence encoding two entries, len(frame.data) == 2, and calling frame.bytes() must reproduce the original byte sequence exactly.

  3. Construction from base64: LppFrame.from_base64(s) must parse a base64-encoded string into the appropriate data entries, yielding len(frame.data) == 2 for input encoding two entries.

  4. Adding data entries: After adding entries via the frame's add_* methods, len(frame.data) must equal the number of entries added. The following add methods must each append one entry to frame.data:

    • add_digital_input(channel, value)
    • add_digital_output(channel, value)
    • add_analog_input(channel, value)
    • add_analog_output(channel, value)
    • add_temperature(channel, value)
    • add_humitidy(channel, value) (note this exact spelling)
    • add_pressure(channel, value)
    • add_gyrometer(channel, x, y, z)
    • add_gps(channel, x, y, z)
    • (any other existing sensor add methods used for luminosity/other sensors that append one entry)

    For example, adding four analog I/O entries results in len(frame.data) == 4; adding six mixed sensor entries results in len(frame.data) == 6.

Summary

Change the frame's data-entries collection from a method-based accessor to a directly accessible public attribute named data. All parsing, construction, byte serialization, and entry-adding behavior must remain unchanged; only the means of accessing the entries collection changes from a call to an attribute reference.
