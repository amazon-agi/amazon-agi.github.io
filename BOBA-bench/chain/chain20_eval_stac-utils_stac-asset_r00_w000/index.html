Overview

Public API Requirements

A class FilesystemClient must be added, one that can be imported directly from the top-level package:

from stac_asset import FilesystemClient
FilesystemClient

  • Constructing an instance must work with no arguments:

    client = FilesystemClient()

  • An asynchronous method must be offered by the class, with the following signature:

    async def download_href(self, href: str, path: str | os.PathLike) -> None
    • href points at a file that exists on the local filesystem (an ordinary filesystem path string, not a URL).
    • path identifies the destination location on the filesystem; the file's contents must be written there.

    Behavior of the method:

    • Reading the file at href and writing its exact byte contents to path is what the method must do.
    • After the method finishes running, the file at path must exist and be byte-for-byte identical to the source file (same size and contents).
    • At exactly the supplied path, the destination file gets created (or overwritten).

Pre-existing Public API (must remain importable and callable)

Every name in the list that follows must stay importable directly from stac_asset, and its behavior must match the description. They get exercised alongside the new client and must not regress:

  • stac_asset.download_href(href: str, path: str | os.PathLike) -> Awaitable[None]

    • The resource at an HTTP(S) href gets downloaded asynchronously, with its bytes written out to path.

  • stac_asset.download_asset(asset: pystac.Asset, directory: str | os.PathLike) -> Awaitable[None]

    • The asset that asset.href references is downloaded asynchronously into the supplied directory.

  • stac_asset.open_href(href: str) -> AsyncIterator[bytes]

    • The bytes of the resource at an HTTP(S) href are yielded asynchronously, in chunks.

  • stac_asset.open_asset(...) / opening of an asset object: the outcome is an async byte-chunk iterator over an asset that a pystac.Asset references.

  • stac_asset.S3Client — a client class carrying an async download_href(self, href: str, path: str | os.PathLike) -> None method, used for downloads from s3:// hrefs.

  • Callers await every client download_href method and the top-level download_href/open_href functions (or async-iterate them), because these are coroutines / async iterators.
  • In the filesystem client's case specifically, no network access is involved; the source is read directly from the local disk.
  • The output of the download/copy must preserve the source file exactly. When the reference test asset is used, the output file that results comes out at 31367 bytes in size, and its contents match the source file's contents exactly.
