Overview

from stac_asset import FilesystemClient
FilesystemClient

    client = FilesystemClient()

  • Must provide an asynchronous method with the following signature:

    async def download_href(self, href: str, path: str | os.PathLike) -> None
    • href is a path to an existing file on the local filesystem (a plain filesystem path string, not a URL).
    • path is the destination filesystem location where the file contents must be written.

    Behavior:

    • The method must read the file located at href and write its exact byte contents to path.
    • After the method completes, the file at path must exist and be byte-for-byte identical to the source file (same size and contents).
    • The destination file is created (or overwritten) at exactly the given path.

    • Asynchronously downloads the asset referenced by asset.href into the given directory.

  • stac_asset.open_href(href: str) -> AsyncIterator[bytes]

    • Asynchronously yields the bytes of the resource at an HTTP(S) href in chunks.

  • stac_asset.open_asset(...) / opening of an asset object: an async byte-chunk iterator over an asset referenced by a pystac.Asset.

Overview

Extend the existing FilesystemClient class in the stac_asset package with a new asynchronous method for downloading all assets of a STAC Item to a local directory and writing the updated Item metadata to disk.

The stac_asset package already exposes a FilesystemClient class that can be imported as:

It currently provides an async method:

which copies the file at href to the local destination path.

Required New Behavior

Add a new async method to FilesystemClient:

async def download_item(self, item, directory) -> None
Parameters
  • item: a pystac.Item instance that has one or more assets.
  • directory: a path (e.g. a pathlib.Path or path string) to an existing local directory into which the item and its assets will be downloaded.
Behavior

When called, the method must:

  1. Download each asset referenced by the item. For every asset in item.assets, copy the file at the asset's href into the target directory.   • The item file must be named exactly {item.id}.json.
  • Asset hrefs in the persisted item must be relative and prefixed with ./.
