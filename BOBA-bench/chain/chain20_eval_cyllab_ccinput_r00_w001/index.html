Problem

Basis set names must be resolved even when the user writes them in a non-canonical but recognizable form. The lookup currently only succeeds for one exact spelling of a basis set name, so common variations fail with an "Unknown basis set" error.

Required Behavior

When resolving a basis set name provided in custom_basis_sets, the name must be normalized before lookup so that spelling variations that differ only by the following are treated as equivalent to the canonical name:

  • Case — comparison must be case-insensitive (e.g. Def2TZVPD, def2tzvpd, DEF2TZVPD all resolve).
  • Hyphens — a hyphen (-) may or may not be present (e.g. def2-tzvpd resolves the same as def2tzvpd).
  • Spaces — whitespace may or may not be present (e.g. def2 TZVPD and Def2 tzvpd resolve the same as def2tzvpd).

In other words, two basis set names are equivalent if they become identical after removing hyphens and whitespace and lowercasing.
